FAQ

자주 묻는 질문

버스커와 셀러는 어떻게 선정되나요?

관리자 페이지에서 행사 일정별로 신청자를 검토하고, 버스커는 승인 기준, 셀러는 결제 완료 기준으로 노출 및 확정됩니다.

GitHub Pages에서도 신청 저장이 되나요?

이 `index.html`은 정적 배포용입니다. 신청 저장, 관리자 로그인, 실시간 일정 연동은 Next.js 서버 배포 환경에서 동작합니다.

신청 확인은 어디서 하나요?

정식 배포에서는 `버스커 신청 확인`, `셀러 신청 확인` 페이지에서 이름과 휴대폰 번호로 상태 조회가 가능합니다.
